Chercher des sons en ligne

Sons proposés par myinstants.com

1. Installer le micro virtuel

Pour que Discord entende les sons, l'app les joue dans un « micro virtuel » gratuit : VB-Audio Virtual Cable.

  1. Télécharge le pack Windows sur le site de VB-Audio.
  2. Décompresse-le, puis clic droit sur VBCABLE_Setup_x64.exe → « Exécuter en tant qu'administrateur » → Install Driver.
  3. Redémarre ton PC si l'installeur le demande, puis reviens ici.

2. Choisir ton casque et ton micro

Ta voix passera par l'app, puis dans Discord avec les sons.

3. Régler Discord

  1. Discord → Paramètres utilisateur → Voix et vidéo.
  2. Périphérique d'entrée : choisis CABLE Output (VB-Audio Virtual Cable).
  3. Désactive la suppression du bruit (Krisp) et l'annulation de l'écho : sinon Discord filtre une partie des sons. Pas d'inquiétude pour ton clavier, l'app nettoie ton micro elle-même.
  4. En mode Détection de la voix, désactive « Déterminer automatiquement la sensibilité » et mets le curseur presque tout à gauche, pour que les sons passent même quand tu ne parles pas.

Tu peux revenir à cet assistant à tout moment depuis les réglages.
