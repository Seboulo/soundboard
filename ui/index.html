    1. Installer le micro virtuel

    Pour que Discord entende les sons, l'app les joue dans un « micro virtuel » gratuit : VB-Audio Virtual Cable.

    1. Télécharge le pack Windows sur le site de VB-Audio.
    2. Décompresse-le, puis clic droit sur VBCABLE_Setup_x64.exe → « Exécuter en tant qu'administrateur » → Install Driver.
    3. Redémarre ton PC si l'installeur le demande, puis reviens ici.

    2. Choisir ton casque et ton micro

    Ta voix passera par l'app, puis dans Discord avec les sons.

    3. Régler Discord

    Dans Discord : Paramètres utilisateur → Voix et vidéo.

    1. Périphérique d'entrée : CABLE Output (VB-Audio Virtual Cable)C'est par là que passent ta voix et les sons.
    2. Suppression du bruit (Krisp) et annulation de l'écho : désactivéesSinon Discord filtre une partie des sons. L'app nettoie déjà ton micro. Sur des enceintes (sans casque), garde l'annulation de l'écho.
    3. Contrôle automatique du gain : désactivéSection Traitement de la voix. L'app règle déjà ton volume, deux réglages automatiques font « pomper » le son.
    4. Atténuation : 0 %Sinon Discord baisse les sons dès que quelqu'un parle. Pareil dans Windows : Panneau de configuration → Son → Communications → « Ne rien faire ».
    5. Détection de la voix : sensibilité manuelle, curseur presque tout à gauchePour que les sons passent même quand tu ne parles pas.

    Tu peux revenir à cet assistant à tout moment depuis les réglages.
